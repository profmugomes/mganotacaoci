# MGAnotacaoCI

Desenvolvi esse sistema de anotação básico ao vivo no YouTube, apenas para mostrar como estudar framework nos dias atuais.

## Tecnologias Utilizadas

- Apache2 (Servidor Web)
- PHP 8.6 (Linguagem de Programação)
- MariaDB 11.8.6 (Banco de Dados)
- CodeIgniter 4.7 (Framework)
- Bootstrap 5 (framework front-end)
- Kate 25.12.3 (Editor)
- MiNav 1.0 (Browser que desenvolvi)

MiNav é um projeto que desenvolvi em ao vivo em outra live, em Gambas3, para navegar no projeto sem a necessidade de usar navegadores pesados.
